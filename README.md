# shed-design

Site planning for a metal building, noise and privacy screening, and other improvements at a
house in southwest Austin, Texas.

- **[`site/notes.md`](site/notes.md)** has the running record of facts, decisions and open
  questions.
- **[`site/site-b.png`](site/site-b.png)** shows the chosen building site.
- Other maps are in [`site/`](site). The scripts in [`tools/`](tools) render them
  (`uv run tools/<script>.py`).
- [`CLAUDE.md`](CLAUDE.md) explains the layout, coordinate frames and conventions.
